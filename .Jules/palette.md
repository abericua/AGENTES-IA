## 2024-09-06 - Semantic HTML Forms
**Learning:** Replaced stylized `<div>` labels with proper semantic `<label>` elements. Remember to add `display: block` in CSS when converting block-level elements like `<div>` to inline elements like `<label>` to preserve layout properties like `margin-bottom`.
**Action:** Always prefer semantic HTML elements over stylized `<div>` or `<span>` for UI components like form labels. Ensure `<label>` tags use the `for` attribute and are linked to their respective input elements via IDs to provide accessible associations for screen readers.
