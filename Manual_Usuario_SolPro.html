SolPro AI Assistant

Versión 1.0

Este manual detalla cómo operar, integrar y maximizar el potencial de tu nuevo sistema de Orquestación Local de 3 Cerebros.

1. Introducción al Sistema

SolPro AI utiliza un pipeline de procesamiento secuencial diseñado para minimizar errores humanos y técnicos mediante el uso coordinado de tres modelos de inteligencia artificial:

Gemma 4 (26B) El Ingeniero Principal. Crea la lógica base y resuelve el problema técnico.
Llama 3 (8B) El Arquitecto Revisor. Corrige errores, aplica estándares PEP8 y añade seguridad.
Qwen (0.8B) El Editor Corporativo. Ajusta el tono al español profesional y limpia el código.

2. Instrucciones de Operación

Cómo iniciar el asistente:

  • Ve a la carpeta AGENTES IA en tu escritorio.
  • Haz doble clic en el archivo Lanzar_Asistente.bat.
  • Se abrirá la interfaz gráfica (GUI) con el logotipo futurista de SolPro.

Pasos para generar una herramienta:

  1. Tarea: Describe en lenguaje natural lo que necesitas programar.
  2. Nombre: Elige cómo quieres llamar al archivo (ej: validador_precios.py).
  3. Ejecutar: Haz clic en el botón azul de "INICIAR PIPELINE".

3. Integración con Proyectos

Cuando trabajemos juntos en el chat, SolPro AI es tu Laboratorio Local:

  • Privacidad Total: Procesa datos sensibles de tu empresa localmente sin subirlos a la nube.
  • Refinamiento Industrial: Toma cualquier código que yo te dé y pásalo por SolPro para hacerlo "Robusto para Producción".
  • Generación de Módulos: Mientras diseñamos un gran sistema, usa SolPro para crear las pequeñas herramientas de automatización que lo acompañan.

4. Solución de Problemas

Si el sistema parece no responder:

  • Verifica Ollama: Asegúrate de que el servidor esté activo (icono en la barra de tareas).
  • Memoria RAM: Cerrar otras aplicaciones pesadas ayuda a que modelos grandes como Gemma 26B carguen más rápido.
  • Timeout: El sistema tiene 10 minutos de espera. Si tarda, es porque está haciendo "swapping" de modelos en tu tarjeta gráfica o RAM.

4. Integración Avanzada

Con Proyectos Existentes

SolPro es un "Refactorizador Maestro". Puedes usarlo para mejorar código que ya tienes:

  • Modo Inyección: Copia el código de un script antiguo y pégalo en SolPro para que el pipeline de 3 cerebros lo actualice a estándares modernos.
  • Extensión de Funciones: Pide a SolPro que cree módulos adicionales para herramientas que ya tienes en otras carpetas.

Sinergia con Antigravity

Antigravity (Estratega): Diseña la arquitectura global y resuelve problemas complejos de lógica.

SolPro (Ejecutor): Toma las ideas de Antigravity y las convierte en scripts locales robustos, seguros y perfectamente documentados.
